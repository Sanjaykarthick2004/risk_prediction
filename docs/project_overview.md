# Project Overview

## Title
Explainable Multimodal AI-Based Athlete Injury Risk Prediction Using XGBoost and SHAP

## Project Level
This is a **college / final-year academic project** — a research prototype, not a production system.

## Problem Statement
Sports injury risk is influenced by many interacting factors — training load, physiological
condition, recovery, sleep, stress, and injury history. Existing tools often consider only a
few variables, or predict risk without explaining *why*. This project builds a multimodal
machine-learning framework that both predicts injury risk **and** explains the prediction.

## Research Population: Running Athletes
This experiment's population is **running athletes** (Sprint, Middle Distance, Long Distance,
Cross Country, and General Running). An earlier version of this prototype used a small
multi-sport sample (~1,200 records spread across seven sports, only ~185 of them running). That
spread the data too thin to support a meaningful single-sport study, and mixed training/injury
characteristics that don't transfer well across sports (e.g. a football "match hours" field has
no running equivalent). A single-sport population with enough records per sport gives more
consistent training-load and injury characteristics to model than combining several
under-represented sports — so this experiment now uses a dedicated, substantially larger
running-athlete dataset (see [methodology.md](methodology.md) for its generation method and
actual size). The pipeline's architecture is sport-agnostic; extending it to another
single-sport study, or a properly-sized multi-sport one, would not require redesigning it.

## Objectives
1. Integrate six athlete data modalities (demographic, training, physiological, recovery,
   lifestyle, injury history) into one feature vector.
2. Predict short-term injury risk probability using XGBoost.
3. Classify risk into LOW / MEDIUM / HIGH using configurable, non-clinical thresholds.
4. Explain every prediction using SHAP (global and individual).
5. Compare XGBoost against conventional ML algorithms.
6. Run a modality-ablation experiment to test whether combining modalities helps.
7. Deliver the whole pipeline through a full-stack web application (React + FastAPI + MongoDB).

## Research Questions
- **RQ1**: Can multimodal athlete information be used to predict injury risk?
- **RQ2**: How does XGBoost compare with conventional ML algorithms?
- **RQ3**: Does combining multiple modalities improve prediction over any single modality?
- **RQ4**: Which features contribute most strongly to the model's predictions?
- **RQ5**: Can SHAP provide understandable explanations for individual predictions?

## Hypotheses
- **H1**: Multimodal feature integration improves prediction over demographic-only information.
- **H2**: Optimized XGBoost performs competitively with, or better than, baseline ML models.
- **H3**: SHAP identifies which features contributed most to individual predictions.

These are evaluated with actual experimental results produced by the app itself
(`POST /api/training/train`, `/api/training/optimize`, `/api/training/ablation`) — see
[experiments.md](experiments.md).

## Research Foundation
Weihao Qu, Dongyang Wang, Ling Zheng, Francisco E. Alvarez, Shobharani Polasa, Jiacun Wang,
"Multimodal Injury Risk and Performance Prediction in Tennis Using Weighted Ensemble Learning,"
*IEEE Systems, Man, and Cybernetics Magazine*, 2026. DOI: 10.1109/MSMC.2026.3685426.

This project does **not** claim to reproduce that paper. It is an independent academic
implementation inspired by its multimodal injury-risk framing, using a different, simpler
pipeline (XGBoost + SHAP instead of a weighted ensemble) and SYNTHETIC DEMONSTRATION DATA
rather than the paper's tennis dataset.

## Contribution
A software-based, explainable, multimodal machine-learning framework that integrates
demographic, training, physiological, recovery, lifestyle, and injury-history information for
athlete injury-risk prediction using XGBoost, explained with SHAP. XGBoost and SHAP themselves
are not novel — the contribution is the integrated, reproducible framework and application.

## Disclaimer
This application is an academic research prototype for sports injury-risk prediction.
Predictions are generated using machine-learning models and should not be interpreted as
medical diagnoses, clinical decisions, or treatment recommendations. The system has not been
clinically validated.

## "How much data did you collect?" (viva answer)
None of the athlete data in this prototype was collected from real people. The current
prototype uses a **synthetic running-athlete dataset** (10,000 records by default, configurable
via `settings.synthetic_dataset_size`), generated by a documented, seeded, reproducible script
(`app/ml/data_loader.generate_synthetic_dataset`, `random_state=42`) for academic
experimentation and software validation — see [methodology.md](methodology.md) for exactly how
it's generated and what relationships are built into it. Real-world athlete data collection and
prospective clinical validation are future work, not part of this submission. The Dataset page
in the running application always shows the actual record count, feature count, and class
distribution live from the data — never a hard-coded number — so this claim is directly
checkable at any time.
